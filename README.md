# Etereal Wedding Market

Burmese-first storefront with an English switch, bilingual search, favorites, rental date selection, and a local request bag.

The GitHub Pages build lives in `docs/`. In repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/docs**, then save.

To develop locally, run `npm install` and `npm run dev`. After editing the storefront, run `npm run build` and commit the regenerated `docs/` files.

Quote requests and history use the [hosted Etereal app](https://etereal-wedding-market.the-studioeternelle.chatgpt.site/), which requires sign-in and site access. GitHub Pages stores the bag and language in the current browser. The bag does not transfer to the hosted app.
